# Credit Risk & Loan Default Analytics

Predicting loan default and segmenting borrowers by credit risk.

**Stack:** Python, Pandas, Scikit-learn, XGBoost, SHAP

## Data

[Credit Risk Dataset (Kaggle)](https://www.kaggle.com/datasets/laotse/credit-risk-dataset).
Download `credit_risk_dataset.csv` into `data/raw/` (not included in this repo).
